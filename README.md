# 📗 c_sharp_theory — C# 기초 문법 학습

> Unity 개발을 위해 C# 문법을 콘솔 예제로 하나씩 정리한 학습 저장소입니다. (.NET 5)

| | |
|---|---|
| **언어 / 도구** | C#, .NET 5 콘솔 앱, Visual Studio |
| **구성** | `UnityLesson_CSharp/` 아래 주제별 프로젝트 |

## 다룬 주제
- **기초**: 연산자, `if`, `for`, `while`, 배열, 컬렉션, `enum`과 `switch`
- **함수**: 메서드, `static`, `delegate`
- **객체지향**: 클래스, 객체 생성, 상속과 인터페이스(`IBreather`, `ITwoLeggedWalker` 등)
- **미니 예제**: `DiceGame`(타일 상속 구조), `HorseRacing`

여기서 익힌 문법은 [unitygame](https://github.com/Pimpers/unitygame)과 [고양이 용병단](https://github.com/Pimpers/team)에서 실제 게임 코드로 사용했습니다.
